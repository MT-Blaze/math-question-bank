                                难度梯度定义（L1–L5）
                            

                            录题与组卷时按此梯度定位题目层级
                        

                        

                            

                                
                                    

                                        层级
                                        名称
                                        含义
                                        典型行为
                                        行为细目
                                    

                                
                                

                                    

                                        L1
                                        概念理解
                                        识记定义、符号、表示，理解公式定理的条件
                                        
                                            能说出
                                            能辨认
                                            能举例
                                        
                                        
                                            
├─ 定义、符号、表示：识记并理解数学基本语言，知道概念的内涵与外延

                                            
└─ 公式定理的条件与识记：明确公式成立的前提条件，能准确回忆并辨认

                                        		
                                    


                                    

                                        L2
                                        基础运算
                                        直接套公式、代入、化简、计算、图象识别、表示互化
                                        
                                            会代公式
                                            会算
                                            会画图
                                            会转换
                                        
                                        
                                            
├─ 直接套公式：题目形式与公式匹配，直接代入求解

                                            
├─ 代入化简计算：进行常规的代数运算、化简与求值

                                            
└─ 图象识别 / 表示互化：能看懂基本图象，或进行不同表示法之间的转换

                                        		
                                    


                                    

                                        L3
                                        性质应用
                                        利用性质进行比较、判断、含参简单讨论、变形应用
                                        
                                            会比较
                                            会判断
                                            会由性质求参数
                                        
                                        
                                            
├─ 利用性质比较判断：借助单调性、奇偶性等性质进行大小比较或正误判断

                                            
├─ 含参简单讨论：参数介入基础题型，需要简单的分类讨论

                                            
└─ 性质变形应用：将公式性质进行逆用、变形或初步综合

                                        		
                                    


                                    

                                        L4
                                        综合运用
                                        多知识点交汇、常规分类讨论、标准压轴题，灵活综合运用
                                        
                                            能拆解综合题
                                            能多步推理
                                        
                                        
                                            
├─ 多知识点交汇：多个章节或模块的知识相互结合，需要拆解与多步推理

                                            
├─ 常规分类讨论：有相对固定套路，但需考虑多种情况的综合分析

                                            
└─ 标准压轴题：试卷中难度较大，考查综合灵活运用能力的常规难题

                                        		
                                    


                                    

                                        L5
                                        创新拓展
                                        新定义、开放探究、数学建模、跨章节深度综合、竞赛强基衔接
                                        
                                            能迁移
                                            能创造
                                            能探究
                                        
                                        
                                            
├─ 新定义 / 新运算：现场理解并应用新概念、新运算规则

                                            
├─ 开放探究：条件或结论不唯一，需要探索、猜想并论证

                                            
├─ 数学建模：将实际情境转化为数学模型并求解

                                            
├─ 跨章节深度综合：融合多个章节核心思想，深层次综合运用

                                            
└─ 竞赛 / 强基衔接：超出常规高考要求，面向竞赛或强基计划的拔高题

                                        		
                                    


                                
                            

                        

                    

                


                
                

                    

                        

                            
                            JSON 配置编辑器
                        

                        
                    

                    

                        
                    

                    

                        
配置说明：

                        
1. question_types: 题型列表。例如：{"value": "single_choice", "label": "单选题"}。

                        
2. difficulties: 难度等级列表。必须包含 value, label 和 color 属性。color 使用 Tailwind CSS 类名控制徽章样式。

                        
3. curriculum: 树状大纲目录结构。格式为："册次名称": {"章节名称": [{"name": "小节名称", "topics": [{"id": "k_xxx", "name": "考点1"}]}]}（考点元素为 {"id", "name"} 对象，id 留空则由系统自动生成；重命名考点只改 name，题目与筛题自动跟随）。修改并保存后，AI 智能分类与试卷智能拆解将立刻感知并应用新大纲！
