## 2. 上游 v2.1.9 → v2.2.3 实际改了什么

### ① 【重点】新增录入后置清洗：裸公式自动补 `$...$`

**新文件 `mathbank/math_markdown.py`（8.2 KB，你这边完全没有）**

入口：`normalize_question_math_markdown(value) -> str`

设计取向是**保守修补**，只动「高置信度数学串」，其余一律原样：

- **先保护（占位符化）**，绝不会被误伤的对象：
  ```` ```代码块``` ````、`` `行内代码` ``、Markdown 图片 `![](...)`、公式锁定引用 `[[MBM_...]]`、
  插图坐标 `[ILLUSTRATION_BOX: ...]`、已有 `$...$` / `$$...$` / `\(...\)` / `\[...\]`、
  `tabular/tabularx/longtable/tblr/choices` 等环境（含嵌套）、
  `\item` `\fillin` `\paren` `\textbf{...}` `\includegraphics{...}`、HTML 标签。
- 其中 `equation/align/gather/multline/displaymath` 等**本来就在数学模式**的环境保持原定界符，
  不重复包 `$`；`cases/aligned/matrix/array/split` 等**内层**环境整体包一层 `$`。
- **再判定**：一个「数学串」只有在满足以下任一条件才补 `$`：
  1. 含**非结构性** LaTeX 命令（排除 `begin/end/item/hline/fillin/paren/textbf/
     includegraphics/multicolum/midrule/toprule/bottomrule/centering/cline/renewcommand`）；
  2. 出现上下标 `x^2` / `x_1`；
  3. 出现 `a=b` / `a<b` / `a>b` 这种关系符；
  4. 出现函数形式 `f(...)`；
  5. 出现坐标形式 `(1, 2)`。
- 逐行处理，中文自然被留在 `$` 外面。

**两个调用点（都在 main.py）：**

| 位置 | 场景 |
|---|---|
| `main.py:4044-4047` | **批量拆题落库前**：对每题的 `content` 与 `answer_markdown` 各跑一次（紧跟在「静默净化 `[EXTRACTED_ORIGINAL]`」之后） |
| `main.py:1137` | **单题 OCR 通道**：剔除 `[ILLUSTRATION_BOX:...]` 之后立刻跑，注释明确写了「先删标记再补公式，否则 `ILLUSTRATION_BOX` 里的下划线会被当上标，清标记后留下空 `$$`」 |

> 你这边 `parsing_pipeline.py:286` / `routes_paper.py:294` **只有静默净化，没有这一步** ——
> 这正是你觉得「清洗规则变了」的地方。

### ② 提示词（prompts.py）变化

**上游新增（你没有）：**

- **规则 3 扩展**：`content` 与 `answer_markdown` 中的数学片段**必须**完整置于 `$...$` 或 `$$...$$` 内，
  中文留外面；保留已有定界符、不得重复包裹。给了正例（`当 $x \geqslant 0$ 时`、
  `$C: \frac{x^2}{a^2}+\frac{y^2}{b^2}=1$`、`$\triangle PQR$ 的面积`）和禁令
  （禁止裸输出 `x_1`、`y^2`、`\frac`、`\geqslant`、`\subseteq`、`\triangle`）。
- **规则 3.1 新增**：向量字形忠实原文 —— 粗斜体 `$\boldsymbol{a}$`、粗正体 `$\mathbf{a}$`、
  箭头 `\vec` / `\overrightarrow` 都要保留，**不得凭题意改字形**。
- **规则 6 收紧**：客观题答案**仅在规则允许时才输出**；「若规则要求空字符串则保持空白，不得自行生成」。
- **AI 解题放宽**：从「严禁使用微积分」改为「**允许**高中课程内的导数及其应用；只禁洛必达、泰勒、积分等大学方法」。
- **Bug 修复**：`build_ai_solve_prompts` 末尾新增
  `system_instructions.replace("\\\\textbf", "\\textbf")` —— 解决提示词标题里 `\textbf` 被写成双反斜杠。

**你有、上游没有（覆盖会丢，见第 3 节）：** 规则 6.1（answer_markdown 三段式格式）、
6.2（水印/商标过滤）、单文件 TeX 第 4 条的答案区关联强化、第 9 条「锁消费硬约束」。
