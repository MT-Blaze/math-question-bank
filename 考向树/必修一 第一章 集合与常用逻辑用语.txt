├─ 1.2 集合间的基本关系
│  ├─ L1 概念理解
│  │  ├─ 考向1：子集、真子集、集合相等的概念
│  │  │  └─ 例：A={1,2}，B={1,2,3}，则A⊆B，A⊂B。
│  │  └─ 考向2：空集的理解与特殊性
│  │     └─ 例：∅⊆{1}，∅⊂{1}；∅⊆∅，但∅⊄∅。
│  │
│  ├─ L2 基础运算
│  │  ├─ 考向3：子集 / 真子集的个数
│  │  │  └─ 例：{1,2,3}的子集有2³=8个，真子集有7个。
│  │  └─ 考向4：集合间的关系判断
│  │     └─ 例：A={x|x>1}，B={x|x>2}，则B⊆A。
│  │
│  ├─ L3 性质应用
│  │  ├─ 考向5：由包含关系求参数
│  │  │  └─ 例：A={1,2}，B={1,a}，若B⊆A，则a=2。
│  │  └─ 考向6：由集合相等求参数
│  │     └─ 例：A={1,a}，B={1,2}，若A=B，则a=2。
│  │
│  ├─ L4 综合运用
│  │  └─ 考向7：含参讨论（空集优先）
│  │     └─ 例：A={x|1≤x≤2}，B={x|m≤x≤m+1}，若B⊆A，求m范围 → 需先讨论B=∅。
│  │
│  └─ L5 创新拓展
│     └─ 考向8：新定义子集族 / 开放构造
│        └─ 例：定义“子集族”为所有子集构成的集合，则{1,2}的子集族为{∅,{1},{2},{1,2}}。

│  ├─ L1 概念理解
│  │  ├─ 考向1：交集、并集、补集的概念与符号

│  │     └─ 例：U={1,2,3}，A={1}，则∁ᵤA={2,3}。

│  │  ├─ 考向3：直接求交、并、补
│  │  │  └─ 例：A={x|x>1}，B={x|x<3}，则A∩B={x|1<x<3}。
│  │  └─ 考向4：交并补混合运算与数轴/Venn图
│  │     └─ 例：∁ᵤ(A∪B) = (∁ᵤA)∩(∁ᵤB)。

│  ├─ L3 性质应用

│  ├─ L4 综合运用
│  │  └─ 考向6：含参讨论（空集优先）
│  │     └─ 例：A={x|1≤x≤3}，B={x|m≤x≤m+1}，若A∩B=∅，求m范围。

│  └─ L5 创新拓展
│     └─ 考向7：新定义集合运算

├─ 1.4 充分条件与必要条件
│  ├─ L1 概念理解
│  │  └─ 考向1：充分、必要与充要的定义
│  │     └─ 例：若p⇒q，则p是q的充分条件，q是p的必要条件。
│  │
│  ├─ L2 基础运算
│  │  ├─ 考向2：条件的判断（四种关系辨析）
│  │  │  └─ 方法：直接推理、集合法、等价转化法
│  │  │     例：判断“x=1”是“x²=1”的什么条件 → 充分不必要。
│  │  └─ 考向3：条件的选择
│  │     └─ 例：使“x>1”成立的一个充分条件是（  ）→ x>2。
│  │
│  ├─ L3 性质应用
│  │  ├─ 考向4：由条件关系求参数
│  │  │  └─ 例：p：x>a，q：x>1，若p是q的充分条件，则a≥1。
│  │  └─ 考向5：充要条件的证明
│  │     └─ 例：证明“x=1”是“x²-2x+1=0”的充要条件。
│  │
│  ├─ L4 综合运用
│  │  └─ 考向6：含参讨论（充要条件与集合相等）
│  │     └─ 例：A={x|x²-3x+2≤0}，B={x|x²-(a+1)x+a≤0}，若p是q的充要条件，求a → a=2。
│  │
│  └─ L5 创新拓展
│     └─ 考向7：新定义条件关系 / 开放构造
│        └─ 例：定义“p是q的充分不必要条件”为p⇒q且q⇏p，构造满足条件的p、q。

└─ 1.5 全称量词与存在量词
   ├─ L1 概念理解
   │  ├─ 考向1：全称命题的判断
   │  │  └─ 例：识别“∀x∈R，x²≥0”是全称命题，理解∀的含义。
   │  ├─ 考向2：特称命题的判断
   │  │  └─ 例：识别“∃x∈R，x²=1”是特称命题，理解∃的含义。
   │  └─ 考向3：命题的否定
   │     └─ 规则：全称变特称，特称变全称，条件不变，结论相反。
   │        例：¬(∀x∈R，x²≥0) → ∃x∈R，x²<0。
   │
   ├─ L2 基础运算
   │  └─ 考向4：判断命题的真假（全称/特称）
   │     └─ 例：判断“∀x∈R，x²>0”真假 → 假，x=0时x²=0。
   │
   ├─ L3 性质应用
   │  └─ 考向5：由命题的真假求参数
   │     └─ 例：若“∀x∈[1,2]，x-a≥0”为真，求a → a≤1。
   │
   ├─ L4 综合运用
   │  └─ 考向6：含参讨论
   │     └─ 例：若“∃x∈[1,2]，x²-a≤0”为真，求a → a≥1。
