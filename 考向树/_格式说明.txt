考向树 TXT 底层文件（本文件不会被同步，可随意修改或删除）

======================================================================
一、放哪里
======================================================================
本目录下的 *.txt 就是「考向树」的底层源文件，与网页端大纲双向同步：

  * 改完 TXT  →  网页端「设置 → 知识点树」点「TXT → 网页」（或重启服务）
  * 网页改完  →  同一处点「网页 → TXT」（保存大纲时也会自动回写）

也可以在命令行执行：
  python -m mathbank.kaoxiang_tree status   # 查看两边是否一致
  python -m mathbank.kaoxiang_tree pull     # 以 TXT 为准刷新网页
  python -m mathbank.kaoxiang_tree push     # 以网页为准回写 TXT

======================================================================
二、文件名规则
======================================================================
  <册次> <章标题>.txt        例：必修一 第一章 集合与常用逻辑用语.txt
文件名里的册次决定这一章挂在哪一册；章标题用来匹配网页里的章
（“第一章 xxx” 与网页里的 “1. xxx” 视为同一个章）。
以 _ 开头的文件（如本说明）会被忽略。

======================================================================
三、正文格式
======================================================================
章 → 节 → L1~L5 难度层 → 考向（可带例：）

  第一章 集合与常用逻辑用语
  │
  ├─ 1.1 集合的概念
  │  ├─ L1 概念理解
  │  │  ├─ 考向1：集合判断
  │  │  │  └─ 例：判断“小于5的自然数”能否构成集合 → 能。
  │  │  └─ 考向2：元素与集合的关系
  │  │     └─ 例：0∈N，0∉N*；√2∉Q。
  │  │
  │  ├─ L2 基础运算
  │  │  └─ 考向3：集合的表示方法
  │  │     └─ 例：{x∈Z | -1<x<3} = {0,1,2}。
  │  └─ L5 创新拓展
  │     └─ 考向4：新定义集合 / 新运算
  │
  └─ 1.2 集合间的基本关系
     ├─ L1 概念理解
     │  └─ 考向1：子集、真子集、集合相等的概念
     └─ L5 创新拓展

写法要点：
  1. 第一行是章标题，其余行用「节 / L层 / 考向 / 例」四类标识开头；
  2. 「节」以数字编号开头：1.1、3.1.1 都可以（3.1.1 会自动挂在 3.1 分组下）；
  3. 「L层」写 L1~L5，后面可跟中文标题，标题会被记住；
  4. 「考向」写「考向N：名称」，序号只作参考，保存时会按出现顺序重新编号；
  5. 「例：」写典型行为，另起一行写在考向下面即可；
     方法/规则/正向/逆向/要点/说明/易错 也可以作为补充行，会并入示例；
  6. 树线（├─ │ └─）和纯空格缩进都支持，回写时会沿用你原来的风格。

======================================================================
四、注意事项
======================================================================
  * TXT 里删掉的考向，如果仍被题目引用，会保留在网页大纲里，避免题目悬空；
  * 考向 id 由「册次/章/节/名称」生成，改名会生成新 id；同名考向会复用原 id；
  * 同步只影响本目录下有对应 TXT 的那些章，其它章不受影响。
