第二章 一元二次函数、方程和不等式
│
├─ 2.1 等式性质与不等式性质
│  ├─ L1 概念理解
│  │  └─ 考向1：用不等式（组）表示不等关系
│  │     └─ 例：某商品单价不超过10元且不少于5元 → 5≤x≤10。
│  │
│  ├─ L2 基础运算
│  │  ├─ 考向2：不等式的基本性质
│  │  │  └─ 例：a>b ⇒ a+c>b+c；a>b，c>0 ⇒ ac>bc。
│  │  │
│  │  └─ 考向3：多项式比较大小
│  │     └─ 例：比较 x²+1 与 2x → 作差得 (x-1)²≥0。
│  │
│  ├─ L3 性质应用
│  │  ├─ 考向4：代数式取值范围
│  │  │  └─ 例：已知 1<a<3，2<b<5，求 a+b 的范围 → 3<a+b<8。
│  │  │
│  │  └─ 考向5：不等式证明
│  │     └─ 例：证明 a²+b² ≥ 2ab → 作差：(a-b)² ≥ 0。
│  │
│  ├─ L4 综合运用
│  │  └─ 考向6：含参讨论
│  │     └─ 例：已知 a>b，比较 a² 与 b² 的大小 → 需讨论 a、b 的符号。
│  │
│  └─ L5 创新拓展
│     └─ 考向7：新定义不等式 / 开放构造
│        └─ 例：定义“a≻b”为 a-b>1，判断其是否具有传递性。
│
├─ 2.2 基本不等式
│  ├─ L1 概念理解
│  │
│  ├─ L2 基础运算
│  │  ├─ 考向1：直接法
│  │  │  └─ 例：x>0，求 x + 1/x 的最小值 → 2，当 x=1 时取到。
│  │  │
│  │  ├─ 考向2：配凑法
│  │  │  └─ 例：x>1，求 x + 1/(x-1) 的最小值 → 配凑得 3，当 x=2 时取到。
│  │  │
│  │  ├─ 考向3：常数代换法（1的代换）
│  │  │  └─ 例：x>0，y>0，x+y=1，求 1/x + 1/y 的最小值 → 4。
│  │  │
│  │  └─ 考向4：消元法
│  │     └─ 例：已知 x+y=1，x>0，y>0，求 xy 的最大值 → 消 y=1-x，xy=x(1-x)≤1/4。
│  │
│  ├─ L3 性质应用
│  │  ├─ 考向5：比较大小
│  │  │  └─ 例：比较 √(ab) 与 (a+b)/2 → √(ab) ≤ (a+b)/2。
│  │  │
│  │  ├─ 考向6：实际应用
│  │  │  └─ 例：用篱笆围矩形，面积固定，求周长最小值 → 正方形时最小。
│  │  │
│  │  └─ 考向7：由基本不等式求参数（恒成立问题）
│  │     └─ 例：若 x>0，x + a/x ≥ 2 恒成立，求 a 的范围 → a≥1。
│  │
│  ├─ L4 综合运用
│  │  └─ 考向8：含参讨论
│  │     └─ 例：求 y = x + a/x（x>0）的最小值，需讨论 a>0、a=0、a<0。
│  │
│  └─ L5 创新拓展
│     └─ 考向9：新定义不等式 / 开放构造
│        └─ 例：定义“a⊙b = a+b+1/(ab)”，求其最小值并构造取等条件。
│
└─ 2.3 二次函数与一元二次方程、不等式
   ├─ L1 概念理解
   │
   ├─ L2 基础运算
   │  ├─ 考向1：解一元二次不等式
   │  │  └─ 例：解 x²-5x+6<0 → 2<x<3。
   │  │
   │  ├─ 考向2：解分式不等式
   │  │  └─ 例：解 (x-1)/(x-2)>0 → x<1 或 x>2。
   │  │
   │  └─ 考向3：解绝对值不等式
   │     └─ 例：解 |x-1|<2 → -1<x<3；解 |x-1|>2 → x<-1 或 x>3。
   │
   ├─ L3 性质应用
   │  ├─ 考向4：三个二次的关系
   │  │  └─ 正向：由函数/方程/不等式写解集；
   │  │     逆向：由解集求参数。
   │  │     例：x²+ax+b<0 的解集为 (1,2) → a=-3，b=2。
   │  │
   │  └─ 考向5：实际应用
   │     └─ 例：用一元二次不等式解决面积、利润、增长率等问题。
   │
   ├─ L4 综合运用
   │  ├─ 考向6：解含参不等式
   │  │  └─ 例：解关于x的不等式 x²-(a+1)x+a<0 → 需按 a>1、a=1、a<1 讨论。
   │  │
   │  └─ 考向7：由能/恒成立求参数
   │     └─ 例：若不等式 x²+ax+1>0 对任意 x∈R 恒成立，求 a 的范围 → -2<a<2。
   │
   └─ L5 创新拓展
      └─ 考向8：新定义 / 开放构造
         └─ 例：定义“二次不等式串”，构造解集为 (1,2)∪(3,4) 的不等式。
