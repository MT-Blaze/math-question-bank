考向1：根式的意义与求范围

topic_id: k_79c61975af（L1）

易错点

偶次开方丢绝对值：\(\sqrt[4]{x^{4}}=|x|\) 而不是 \(x\)。

混淆两种结构：\(\sqrt[n]{a^{n}}\)（\(n\) 偶）对负数也有意义，\((\sqrt[n]{a})^{n}=a\) 却要求 \(a\ge 0\)。

求范围只看被开方数非负，漏掉分母 \(\ne 0\)、零次幂底数 \(\ne 0\)。

给奇次根式多加限制：\(\sqrt[3]{x}\) 中 \(x\in R\)，写 \(x\ge 0\) 反而缩小范围。

解题方法

先定次、再看底：

  1. 读根指数 \(n\)：偶数走「非负」路线，奇数对被开方数不加限制。
  2. 脱根号分两支：\(\sqrt[n]{a^{n}}=|a|\)（\(n\) 偶）、\(=a\)（\(n\) 奇）；\((\sqrt[n]{a})^{n}\) 则恒为 \(a\)。
  3. 带字母先用绝对值兜住，再按条件拆号：由 \(a<0\) 得 \(\sqrt{a^{2}}=-a\)。
  4. 所有限制并列成不等式组后取交集，结果写成集合或区间。

考向2：根式与分数指数幂互化

topic_id: k_270ec79140（L2）

易错点

分子分母颠倒：\(\sqrt[n]{a^{m}}=a^{\frac{m}{n}}\)，根指数 \(n\) 做分母。

底数可能为负时强行互化：教材只在 \(a>0\) 上自由使用分数指数幂法则。

漏负号：\(\dfrac{1}{\sqrt[3]{a^{2}}}\) 应化 \(a^{-\frac{2}{3}}\)，不是 \(a^{\frac{2}{3}}\)。

同一题里根式与指数幂两种写法混着交卷，末了不按要求统一形态。

解题方法

互化口诀：

  1. 根式转指数幂：\(\sqrt[n]{a^{m}}=a^{\frac{m}{n}}\)（\(a>0\)）——被开方数的指数作分子、根指数作分母。
  2. 负指数先提倒数：\(a^{-\frac{m}{n}}=\dfrac{1}{\sqrt[n]{a^{m}}}\)。
  3. 系数移进根号要连幂一起乘：\(a\sqrt{-a}=-\sqrt{(-a)^{3}}\)，别把负号吞进去。
  4. 验算：代一个具体数（如 \(a=16,n=4,m=2\)）确认两式相等。

考向3：根式的化简或求值

topic_id: k_c3b8133184（L2）

易错点

忘记绝对值：\(\sqrt{(1-2x)^{2}}=|1-2x|\)，直接写 \(1-2x\) 在 \(x>\dfrac{1}{2}\) 时为负，与算术平方根矛盾。

\(\sqrt{a^{2}+b^{2}}\) 拆成 \(a+b\)：根号只对积与商可拆，对和差不行。

数字题也算错：\(\sqrt{(-3)^{2}}=3\)；而 \(\sqrt[3]{(-3)^{3}}=-3\) 要留负号。

含参时不做分类讨论，默认字母为正。

解题方法

去根号四步：

  1. 判结构：\((\sqrt[n]{a})^{n}\) 先开方后乘方，恒为 \(a\)；\(\sqrt[n]{a^{n}}\) 才涉及绝对值。
  2. 被开方数分解到最简：\(\sqrt{12}=2\sqrt{3}\)、\(\sqrt{x^{2}y}=|x|\sqrt{y}\)。
  3. 偶次出来挂绝对值再拆号：\(x>\dfrac{1}{2}\) 时 \(|1-2x|=2x-1\)。
  4. 分母有理化用共轭因式。

考向4：分数指数幂的运算

topic_id: k_5d4b148c3e（L2）

易错点

法则用串：\((a^{m})^{n}=a^{mn}\) 而非 \(a^{m+n}\)；\(a^{m}\cdot a^{n}=a^{m+n}\) 而非 \(a^{mn}\)。

负指数忘取倒数：\(2^{-3}=\dfrac{1}{8}\)，不是 \(-8\)。

漏乘系数：\((2a)^{3}=8a^{3}\) 写成 \(2a^{3}\)。

零指数幂忽略前提：\(a^{0}=1\) 需 \(a\ne 0\)，\(0^{0}\) 无意义。

解题方法

统一指数再运算：

  1. 根式全化分数指数幂、分母与负号全化成负指数，统一形态。
  2. 顺序执行：先乘方 \((a^{m})^{n}=a^{mn}\)，再同底乘除 \(a^{m}\cdot a^{n}=a^{m+n}\)、\(\dfrac{a^{m}}{a^{n}}=a^{m-n}\)。
  3. 分数指数相乘先通分：\(a^{\frac{1}{2}}\cdot a^{\frac{1}{3}}=a^{\frac{5}{6}}\)。
  4. 结果不含负指数、不根式与指数幂混写。

考向5：条件等式求值

topic_id: k_430cb9daf3（L3）

易错点

平方漏交叉项：\(\left(x^{\frac{1}{2}}+x^{-\frac{1}{2}}\right)^{2}=x+2+x^{-1}\)，中间的 \(2\) 最常丢。

不构造中间整体就硬算，算量爆炸甚至算不出。

开方只取正根：由 \(\left(x^{\frac{1}{2}}-x^{-\frac{1}{2}}\right)^{2}=6\) 得差为 \(\pm\sqrt{6}\)。

不回代：要 \(x^{2}+x^{-2}\) 却答成 \(x+x^{-1}\)。

解题方法

平方构造 + 整体代换：

  1. 看已知与所求的指数倍数关系：指数翻一倍就先平方。
  2. 造中间量：\(\left(x^{\frac{1}{2}}+x^{-\frac{1}{2}}\right)^{2}=x+2+x^{-1}\)，故 \(x+x^{-1}=m^{2}-2\)。
  3. 更高次再平方一次：\(x^{2}+x^{-2}=(x+x^{-1})^{2}-2\)。
  4. 差式先平方后定号：\((a-b)^{2}=(a+b)^{2}-4ab\)，符号由 \(x\) 的范围决定。

考向6：指数运算的综合运用

topic_id: k_02f8a1788e（L4）

易错点

崩点仍集中在偶次开方漏绝对值与负指数漏倒数，一步错则全题错。

根式、分数指数幂、小数指数三种形态混在一题却不先统一，边算边换形式导致法则用串。

忽略隐含条件：出现 \(\sqrt{-a}\) 即已暗含 \(a\le 0\)，后续拆绝对值必须据此定号。

不同底数硬算法则：\(8\times 4^{2}\) 应先把 \(8=2^{3}\)、\(4=2^{2}\) 归到同底再合并。

结果里同时留着根号、负指数与分数指数，被判「未化到最简」。

解题方法

统一 → 化简 → 还原：

  1. 全式统一形态：根式化分数指数幂、分母化负指数、小数化分数（\(0.25=\dfrac{1}{4}\)）。
  2. 不同底先归同底再算：\(4=2^{2}\)、\(8=2^{3}\)、\(\sqrt{2}=2^{\frac{1}{2}}\)。
  3. 按「先乘方、再乘除、后加减、括号优先」逐项做，每步只动一处便于回查。
  4. 收尾按要求还原形态，并查三件事：根号内无分母、无负指数、无未开尽的因式。
