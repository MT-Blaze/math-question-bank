【一、四条已核实事实 + 两个陷阱（不要重新论证，按结论执行）】

**F1｜开关漂移且无守卫**：默认 `"1"`，注释/docstring/`.env.example`/`AGENTS.md` 全部写着"默认开"，与"暗启动"决议相反；且无任何测试覆盖未设置分支 → 改了不会红。→ 见第零节。

**F2｜`read_timeout` 只能收紧，不能放宽**（`ai_http.py:131`）：
```python
kwargs["timeout"] = min(requested, float(read_timeout) if read_timeout else 30.0)
```
现在能生效纯粹因为 `timeout=180 > 120`。谁把 180 调到 90，修复静默失效且无测试报警。

**F3｜connect 超时被同一处修改放大**：`timeout` 是 scalar，同时管 connect 与 read。修复前 `min(180,30)=30`，修复后 `min(180,120)=120`；而 `robust_request_post`（`ai_http.py:37-49`）对 `ConnectTimeout` 会**无代理重试一次** → 最坏 240s。同时 `_post_bounded` 的 deadline 只在 chunk 循环里检查（`:141`），**连接阶段完全不受 deadline 约束**，`:116-121` 那句 "guarantees the call always comes back" 不成立。

**F4｜降级 = 成功**：`_run_fast_path` 的 `except Exception` 把 AI 失败兜成可用返回值，任务状态/UI/调用方全都认为成功；`degrade_reason` 只存 `str(exc)`，**没有异常类名**；而 `tests/test_pdf_fast_path_ab.py` 全篇只 `print`，**零 assert** → 100% 降级也不会红。

**陷阱 T1｜不要用题干相似度当"快路径成功"的证据**
clean 块正文是本地原样保留的，AI 只拿每块 ≤150 字摘录（`_PDF_CLEAN_EXCERPT`）做分类。所以「正文 100% 一致 + 分类全空」完全可以同时成立——那会显示成漂亮的相似度，实际是 100% 降级。**成功证据只有 `ai_ok is True` 且 `n_unclassified == 0`。**

**陷阱 T2｜老路不是生产线**
`_old_path_measure` 是手抄的请求体，已漂移：读超时私放宽到 420s（生产 `AI_SPLIT_READ_TIMEOUT_SECONDS=240`）、缺 `preserve_extracted_answers=bool(split_info)`、缺页标清理与 `normalize_for_storage`。拿它当基线，比的是"两套手写实现"，不是"两条流水线"。

**严格边界**
- 只动快路径这两个量；`AI_SPLIT_READ_TIMEOUT_SECONDS`（240）与 `AI_SPLIT_DEADLINE_SECONDS`（480）**一个字符都不许动**。

**P0-2｜拆开 connect / read 超时**

`ai_http.py:128-135`
改前：
```python
    kwargs = dict(request_kwargs)
    kwargs["stream"] = True
    requested = float(kwargs.get("timeout") or 60)
    kwargs["timeout"] = min(requested, float(read_timeout) if read_timeout else 30.0)
```
改后目标：`kwargs["timeout"]` 一律归一化为二元组 `(connect, read)`
- `connect = min(调用方给的 connect 或 60, 30.0)` —— connect 上限恒为 30s，**不再被 `read_timeout` 放大**
- `read = min(调用方给的 read 或 60, read_timeout if read_timeout else 30.0)` —— `read_timeout` 从此**可以真正放宽**
- 调用方传进来就是二元组时，直接取其两个分量再分别套上限

**严格边界**
- 纯传输层改动，`_post_bounded` 内不许出现任何业务判断（不认 provider、不认 task 类型、不认模型名）。
- `post_chat_completion` 公开签名不变；`stream=True` 分支（`:187-192`）不受影响。
- `robust_request_post` 的重试语义（仅 ProxyError/ConnectTimeout 重试一次）**保持原样**，不许扩到 ReadTimeout（那会导致重复计费）。
- 行为变化必须写进 PR：现有 scalar 调用者的 connect 会从"等于 timeout"收紧到 30s。这是改善（快速失败 + 可重试），但要显式列出。
- 全量 `pytest tests/ -q` 仍须 1654 passed（本轮新增 2 条测试，所以是 1656）。

**P0-3｜让"降级"变成会红的失败**

`routes_paper.py:1033-1036`
改前：
```python
    except (TaskCancelled,):
        raise
    except Exception as exc:  # 超时/网络/坏JSON/条数不符 → L2 保正文降级
        return _degrade_clean_only(plan, exc, diagnostics)
```
改后目标：
1. 成功路径写 `diagnostics["ai_ok"] = True`；降级路径写 `False`。
2. `degrade_reason` 改为 `f"{type(exc).__name__}: {exc}"[:200]`（**异常类名必须进字符串**，`ReadTimeout` 的 `str()` 里没有类名）。
3. 新增 `diagnostics["ai_error_class"] = type(exc).__name__`。
4. 新增开关 `PDF_FASTPATH_STRICT`（默认 `0`）：置 `1` 时，`_run_fast_path` 的 AI 异常**直接向上抛**，不做 L2 降级。

**严格边界**
- `PDF_FASTPATH_STRICT` 只作用于 `_run_fast_path` 的 AI 异常分支；**不得**影响 L1（`plan.trustworthy=False` 是切块器的合法判定，不是失败，A/B 里那 3 卷不信任卷本来就走 L1）。

- 生产默认 `0`，除新增 `ai_ok`/`ai_error_class` 字段外，全量测试行为不得改变。

【五、执行与判红】

本机是 **Windows PowerShell**，环境变量必须先赋给 `$env:` 再执行，不能写成 `VAR=1 cmd` 形式（那是 bash 语法，PowerShell 会把它当成要执行的命令名并报 `CommandNotFoundException`）。

```powershell
# 1) 先设变量（同一 PowerShell 会话内生效）
$env:PDF_AB_RUN            = "1"
$env:PDF_AB_OLD            = "1"
$env:PDF_FASTPATH_ENABLED  = "1"
$env:PDF_FASTPATH_STRICT   = "1"

# 2) 跑 A/B
.\venv\Scripts\python.exe -m pytest tests\test_pdf_fast_path_ab.py -s -q
```

跑完**立刻清掉**，尤其是 `PDF_AB_RUN`——它会污染后续的全量回归：

```powershell
Remove-Item Env:PDF_AB_RUN, Env:PDF_AB_OLD, Env:PDF_FASTPATH_ENABLED, Env:PDF_FASTPATH_STRICT -ErrorAction SilentlyContinue
```

⚠️ **两个 PowerShell 特有的坑，必须避开**
1. `$env:X` 是**会话级持久**的，不像 bash 的 `VAR=1 cmd` 只对那一条命令生效。设完不删，后面每一次 `pytest` 都会带着 `PDF_AB_RUN=1` → 全量回归会真的去跑联网 A/B 并消耗额度。
2. 不要在一条命令里用 `&&` 串联（PowerShell 5.1 不支持），要用 `;` 或分行。
3. 之后若还要在**同一个 PowerShell 窗口**里启动服务验证"默认关"，务必先执行上面的 `Remove-Item`；否则 `$env:PDF_FASTPATH_ENABLED="1"` 会跟着新进程走，"默认关"名存实亡。

**命中以下任何一条 → 立刻停，把原始异常贴回来，不许 catch 后继续**
- `PDF_FASTPATH_STRICT=1` 下抛出任何 AI 异常（说明还会降级）
